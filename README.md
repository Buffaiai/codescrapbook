# 代码手账本 · Code Scrap

> 两个人合写一页「今天写了啥」的贴纸日记。拖代码条、贴纸、印章到同一页手账上，实时看见对方操作。不是 IDE，是好看的互动手账页。

## ✨ 特性

- 🎨 **手账贴纸风**：点阵纸张、撕边贴纸、纸片代码条、和纸胶带、微倾旋转
- 👥 **双人实时协作**：基于 BroadcastChannel，同房号双窗口即可看到彼此的光标、拖拽与时间线
- 🧩 **丰富素材**：8 段代码条（JS/Python）、12 张文案贴纸、2 枚印章、6 色胶带
- 🖱️ **完整交互**：拖拽移动、旋转、缩放、删除；代码条双击可改文字
- 🔴 **盖章动效**：拖「搞定」「联名」章落下有"啪"的盖章动画
- 📥 **一键导出 PNG**：把整页手账导出成图
- 💾 **本地持久化**：房间状态存 localStorage，刷新不丢

## 🚀 快速开始

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`（或终端提示的端口）。

## 🎬 双人协作演示（开两个窗口）

1. **窗口 A**：点「新建房间」→ 输入昵称（如「阿橘」）→ 选一个贴纸色 → 点「开始写手账」。记下右上角的 **4 位房号**。
2. **窗口 B**：点「加入房间」→ 输入另一个昵称（如「小绿」）→ 选另一个颜色 → 输入窗口 A 的房号 → 点「加入房间」。
3. 两个窗口现在共享同一页手账：
   - 在任意一个窗口拖素材到画布，**另一个窗口会实时出现**。
   - 移动鼠标能看到对方的**幽灵光标 + 昵称**。
   - 右侧**时间线**记录「谁贴了/动了/删了什么」。
4. 点右上角「⬇ 导出 PNG」保存成品。

> 💡 协作基于浏览器 `BroadcastChannel`，同一浏览器的不同标签页/窗口即可演示。跨设备需配合 WebSocket 服务（架构已预留，见 `src/store/useSync.ts`）。

## 🎯 操作说明

| 操作 | 方式 |
|------|------|
| 添加元素 | 从左侧抽屉拖到画布 |
| 移动 | 按住元素拖动 |
| 旋转 | 选中后拖顶部蓝色 ↻ 手柄 |
| 缩放 | 选中后拖右下角绿色 ⤢ 手柄 |
| 删除 | 选中后点右上角红色 × |
| 改代码 | 双击代码条进入编辑，`Cmd/Ctrl+Enter` 保存，`Esc` 取消 |

## 🛠️ 技术栈

- **Vite + React 19 + TypeScript**
- **Zustand** 状态管理 + localStorage 持久化
- **BroadcastChannel** 双人实时同步（光标 / 元素 / 时间线）
- **html-to-image** PNG 导出
- **纯 CSS + SVG feTurbulence** 实现纸张纹理与撕边效果

## 📁 目录结构

```
src/
├── types.ts                 # Room / User / Item 数据模型
├── data/                    # 预设代码段、贴纸、印章
├── store/
│   ├── useRoomStore.ts      # zustand 房间状态
│   └── useSync.ts           # BroadcastChannel 同步
├── components/
│   ├── Home.tsx             # 首页：创建/加入房间
│   ├── Scrapbook.tsx        # 主画布
│   ├── Drawer.tsx           # 左侧素材抽屉
│   ├── CanvasItem.tsx       # 拖拽/旋转/缩放/删除外壳
│   ├── CodeStrip.tsx        # 代码条
│   ├── Sticker.tsx          # 贴纸
│   ├── Stamp.tsx            # 印章
│   ├── Tape.tsx             # 和纸胶带
│   ├── RemoteCursor.tsx     # 对方幽灵光标
│   ├── Timeline.tsx         # 操作时间线
│   └── Toolbar.tsx          # 顶栏（房号/导出/离开）
└── utils/
    ├── exportPng.ts
    └── id.ts
```
